# סדנאות תיפוף

דף נחיתה לסדנאות תיפוף מאת אלעד יעקובוביץ'. כולל עיצוב מרשים בעברית (RTL) עם אנימציות חלקות, טופס יצירת קשר עם שליחת מייל דרך Resend ועיצוב מותאם מובייל.

## תכונות

- דף נחיתה בעברית עם עיצוב מודרני
- אנימציות חלקות עם Framer Motion
- טופס יצירת קשר עם שליחת מייל דרך Resend
- עיצוב מותאם מובייל (Mobile-first)
- עיצוב עם Tailwind CSS 4
- Next.js 16 App Router

## טכנולוגיות

| טכנולוגיה | שימוש |
|-----------|-------|
| [Next.js 16](https://nextjs.org/) | פריימוורק React |
| [React 19](https://react.dev/) | ספריית UI |
| [TypeScript](https://www.typescriptlang.org/) | בטיחות טיפוסים |
| [Tailwind CSS 4](https://tailwindcss.com/) | עיצוב |
| [Framer Motion](https://www.framer.com/motion/) | אנימציות |
| [Resend](https://resend.com/) | שליחת מיילים |

## התקנה

```bash
git clone https://github.com/eladjak/drumming-workshops.git
cd drumming-workshops
bun install
bun dev
```

פתחו [http://localhost:3000](http://localhost:3000) בדפדפן.
